## Project Overview

This project demonstrates practical security governance activities in a simulated environment. It covers environment setup, analysis of governance failures associated with the Equifax data breach, implementation of security governance controls, and security governance metrics and reporting.

## Part 1: Environment Setup
Contains the Docker configuration and supporting evidence for the simulated environment.

## Part 2: Governance Failure Analysis
Contains the Equifax case study comparison, vulnerability assessment results, and supporting analysis.

## Part 3: Governance Control Implementation
Contains the governance control implementation script, implementation report, and verification evidence.

## Part 4: Security Governance Metrics and Reporting
Contains the metrics generation script, executive dashboard, board report, metrics framework, user guide, and visualisations.
